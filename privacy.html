プライバシーポリシー

「黒子 議事録」（以下、本ツール）は、斉藤誠太郎が個人で利用するためのツールです。本人以外の利用は想定していません。

1. 利用する Google ユーザーデータ

本ツールは YouTube Data API を通じて、本人の YouTube チャンネルに対して次の操作のみを行います。

  • 打ち合わせの録画を非公開の動画としてアップロードすること
  • アップロードした動画のタイトルと説明を変更すること

2. データの保存場所

認証に必要な情報は、本人のパソコンの中にのみ保存します。外部のサーバーには保存しません。

3. 第三者への提供

取得したデータを第三者に提供・販売することはありません。

4. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。
